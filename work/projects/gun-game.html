The project

Gun Game is a focused target-shooting prototype built in Unreal Engine. I adapted the default-template gun from projectile behavior to a line trace for hitscan shooting, then connected target response and timer feedback. The breakdown presentation explains the implementation, while a separate feature-lock checklist shows the compact intended scope. Together with the demonstration, these artifacts make it possible to review both the mechanic and the reasoning behind it.
