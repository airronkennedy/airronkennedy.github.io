The project

Airronbot brings birthday reminders, welcome messages, moderator announcements and slash commands into a Discord community. Addressed messages are filtered and sent to a separate external relay, whose authenticated callback delivers text and optional queued speech. The project also includes duplicate protection, voice-state handling and a health dashboard. This is an AI-assisted personal project, and the portfolio distinguishes documented capabilities, generated or adapted code and behavior that still needs a fresh end-to-end demonstration.

What to notice

Follow the path from a Discord event through filtering, relay transport, callback validation and delivery. The inspected code and operations README make the preview/production boundary and queued-versus-finished voice states explicit.

Integration architecture

Discord event → addressed-message filter → bounded relay queue → external service → authenticated callback → text delivery / optional speech. The bot integrates with the relay; it does not generate the answer itself. Duplicate suppression is process-local. Birthdays are stored in local JSON, not PostgreSQL. Preview avoids a second Discord gateway session; persistent voice needs a continuously running process. Queued speech is not listener-confirmed playback.
