Playable Projects · Project & Portfolio I

The project

This Unity archive preserves a Pong implementation with scenes, ball and paddle scripts and a build directory. Selected C# scripts were inspected to identify the ball, paddle and goal-handling responsibilities. The project is a supporting example of turning a recognizable gameplay loop into engine behavior. It gives a concrete starting point for discussing motion, collision, scoring and how game objects work together.

What to notice

The source inspection identifies Ball, Paddle and goal-handling scripts. Review the actual implementation before making claims about a modern rebuilt version.

Implementation inspection

The selected archive contains separate Ball, Paddle, Goal, LeftGoal and EndGame scripts. This separation provides a focused way to discuss object motion, input and scoring responsibilities. No raw source or executable is distributed here; import, dependency review and launch testing remain future work.

Local evidence

These files are hosted with the portfolio and need no Google Drive sign-in. Text exports are labeled separately from original-layout PDFs and editorial briefs.

Ownership & scope

The archive was inspected but not imported or launch-tested in a current editor. A build directory does not establish that an executable still runs, and archived engine/template assets are not all original authorship.
