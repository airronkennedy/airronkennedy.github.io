The project

LightsOut is a compact Unity diagnostic project preserved as a package, with a separate demonstration link. Its button and game-manager scripts can be reviewed as small implementation samples. The combination of source, demo and task-board reference gives more context than a screenshot alone. It is a supporting example of implementing interactions, tracking game state and communicating a small project’s behavior.
