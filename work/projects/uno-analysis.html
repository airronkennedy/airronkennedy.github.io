Game Design · Game Design I

The project

I analyzed UNO as a system of goals, rules and player actions. The document organizes the familiar game into a structured design breakdown instead of relying on familiarity with its brand. This work supports a useful design habit: explaining what players can do, why those actions matter and how rules constrain their choices. It also provides a foundation for comparing existing systems with the original card-game work elsewhere in this portfolio.

What to notice

Read the goal/rule/action structure as a communication sample. The value is in explaining a system clearly enough that another designer can reason about it.
